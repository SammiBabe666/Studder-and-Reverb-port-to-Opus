# sammi.stutter: Hundekraft's STUTTER (OP-1 Workshop 3.1.1), a beat-locked stutter, ported as a native effect type
# for the synth, the drum and the master. blue rate, green mode, white shape, orange chance; on its own page
# shift + blue sets the repeats (2-16), shift + orange freezes (clockwise on, anticlockwise off).
# Its page's picture (the defective tape head) is drawn under the OS's screen, so the OS's off overlay dims it.
# core 2.2: opus_instrument_now, opus_fx_owner, opus_fx_page_shown (the managers' service).
# Deep, read-only: the metronome's beat clock and the tape's speed at firmware #246's addresses (as kennel reads them),
# trusted only while they behave like a clock (1.2: the clock guard); build/opus/nodeep: a build with no deep reads.
